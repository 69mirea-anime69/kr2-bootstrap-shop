# Магазин на Bootstrap

Магазин предметов для рабочего стола: лампы, органайзеры и блокноты.

[Открыть сайт на GitHub Pages](https://69mirea-anime69.github.io/kr2-bootstrap-shop/)

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Это отдельная реализация магазина на Bootstrap. Из КР №1 сохранены предметная область, товары и изображения. Страницы и стили сделаны заново с использованием сетки и компонентов Bootstrap.

## Технологии и подключение

HTML, CSS, Bootstrap **5.3.8** и небольшой JavaScript без дополнительных библиотек.

Bootstrap подключён **локально**, без CDN. Поэтому для просмотра не нужен интернет.

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js" defer></script>
<script src="js/main.js" defer></script>
```

`custom.css` подключается после Bootstrap, чтобы небольшие собственные стили имели приоритет. JS Bundle отвечает за меню, модальное окно, вкладки и accordion. Файлы взяты из [Bootstrap 5.3.8](https://getbootstrap.com/docs/5.3/getting-started/download/), лицензия находится в `vendor/bootstrap/LICENSE`.

## Страницы

- `index.html` — главная: hero-блок, преимущества, популярные товары.
- `catalog.html` — каталог с поиском, фильтрами и сортировкой.
- `product.html` — описание товара, цена, характеристики и уход.
- `order.html` — форма заявки и расчёт суммы.
- `contacts.html` — пример контактов, условия доставки и частые вопросы.

## Сетка и компоненты Bootstrap

Используются `container`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-3` и `g-4`. На узком экране карточки идут в одну колонку, от 768 px — в две, от 992 px — в три.

| Компонент | Где находится |
| --- | --- |
| `navbar`, `collapse` | Меню на всех страницах, раскрывается на телефоне |
| `card` | Карточки товаров, контакты и итог заявки |
| `btn`, `btn-outline-*` | Кнопки и ссылки действий |
| `badge` | Метки «Хит», «Новинка», «Скидка» |
| `alert` | Сообщения и результат проверки заявки |
| `modal` | Окно выбранного товара по кнопке «Заказать» |
| `form-control`, `form-select` | Поля формы и фильтры |
| `input-group` | Префикс +7 у телефона и знак рубля в фильтре |
| `form-check` | Согласие на обработку данных |
| `accordion` | Частые вопросы на странице контактов |
| `nav-tabs` | Характеристики и уход на странице товара |
| `breadcrumb`, `table` | Навигация и таблица характеристик |

## Доработки сверх базового задания

- Локальное подключение Bootstrap и локальные изображения.
- Дополнительная страница контактов с accordion.
- Поиск по названию, фильтр категории и максимальной цены, сортировка по цене. При отсутствии результатов выводится сообщение, есть кнопка сброса.
- Страница товара меняется в зависимости от параметра `product` в ссылке. Например, `product.html?product=organizer` показывает органайзер.
- Кнопка «Заказать» открывает Bootstrap modal с названием и ценой выбранного товара. Ссылка из окна переносит этот товар в заявку.
- В заявке можно менять количество и способ получения. Стоимость товаров и доставки пересчитывается автоматически.
- Обязательные поля проверяются браузером: имя, e-mail, телефон из 10 цифр, товар, количество и согласие. После проверки появляется `alert`.
- На маленьком экране меню сворачивается, колонки перестраиваются. Таблица помещена в `table-responsive`.

## Запуск и проверка

Скачайте репозиторий и откройте `index.html` в браузере. Установка пакетов и сборка не нужны. Также можно запустить из папки проекта:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

1. Перейдите по всем ссылкам меню. В DevTools проверьте ширины 375, 768 и 1440 px: горизонтальной прокрутки быть не должно.
2. На узком экране откройте и закройте меню.
3. В каталоге выберите «Блокноты» или цену до 500 ₽. Должен остаться блокнот. При цене до 100 ₽ появится сообщение об отсутствии товаров. Сброс должен вернуть все три карточки.
4. Проверьте поиск, сортировку «Сначала дешевле» и «Сначала дороже».
5. Откройте описание каждого товара, переключите вкладки «Характеристики» и «Как ухаживать».
6. Нажмите «Заказать». Проверьте название и цену в окне, закройте его крестиком, кнопкой и клавишей Escape.
7. Перейдите из окна к заявке: в списке должен быть выбран нужный товар.
8. Для двух ламп с доставкой итог должен составить **3 280 ₽**: 1 490 × 2 + 300.
9. Попробуйте отправить пустую форму, неверный e-mail или короткий телефон. Браузер должен остановить отправку. Затем заполните корректно и отметьте согласие: появится зелёное сообщение.
10. Проверьте очистку формы и раскрытие вопросов на странице контактов.

Сайт учебный: серверной части, настоящей отправки заявок и оплаты нет. Введённые данные не сохраняются. Контакты и условия доставки приведены для примера.
